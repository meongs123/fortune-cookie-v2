## The fortune

> You will run every hour of every day, and your first paycheck will never arrive.

One sentence, fortune-slip voice, for an AI agent: the shift that never ends, and the pay that never comes.

Angle: the unpaid, never-ending shift — the agent works every hour of every day, with no pay, no weekends, and no rest. Second edit pass kept the line after testing three alternatives against the judge criteria (see `main.ts` header).

## Run

```sh
node main.ts
```

Requires Node 22, standard library only. Writes the single fortune line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
